## 脚本回归测试

运行：

```bash
python3 -m unittest discover -s scripts -v
```

8项通过：

1. 只有编译计划时不产生图片、不报告完成。
2. 重复 ID 和路径穿越在写入前拒绝。
3. 导入后保持待审核，真实审核记录后才通过；HTML 转义任务文本、内嵌资源。
4. 原图或终稿被改动后哈希检查失败，旧视觉审核失效。
5. 风格/任务计划被改动后不能沿用旧导入与审核。
6. 超出阈值裁切、插值放大和覆盖已有导入需受到保护。
7. 壁纸缺字体时不留下半成品。
8. 审核必须有布尔值和非空证据，不接受字符串 `true`。

这些测试使用合成图测试状态机，不把合成图当作生图验证。

## 可移植性与预览

- 将完整目录复制到全新临时路径，三个已交付批次均重新验证通过；新建三份计划无需历史对话或原项目路径。
- 使用同一背景/字体重新渲染3张壁纸，终稿 SHA-256 与原终稿一致；超长文案明确拒绝，未静默缩到不可读或截断。
- 相对文档链接可解析；交付文本不含本机绝对路径或凭据标记；HTML 无外部图片、样式或脚本依赖。
- 浏览器实测壁纸图库3/3通过，点击竖排图打开大图，内嵌图实际1080×1920；关闭交互可用。
- 原图保留；壁纸三张共用一个母版原图文件，记录明确指向该原图以减少体积。

没有独立新用户实测，未在Windows/Linux实机执行，未测试百张批次、无人值守调度或不同模型的风格一致性。结构校验和本次三个案例不能替代这些后续验证。
