# 素材与来源

- `assets/style-packs/*.json`：为本通用工作流编写的教学风格规范。
- `examples/*/tasks.jsonl`：本版本新写的教学主题和短句，不是从参考图复制的文案。
- `examples/*/result/finals/*`：本次通过宿主内置图像工具新生成，或由新生成背景加本地准确排字得到的演示终稿。
- 未收入历史项目原始参考图、公司素材、实拍图库下载、音频、字体文件或历史聊天。
- 文字演示仅随附渲染后的图像及字体哈希，不包含字体软件；使用者重做时自行选择有权使用的字体。
- 示例摄影是生成场景，不是现实地点或动物的纪实证据，也不是实际音频录制来源。

维护者允许使用和修改本版本新生成的演示图片，但不保证独占性或相同图像可以再生成；实际使用还需遵守所用图像工具的适用条款。第三方字体和用户后续输入的素材不在本授权范围内。
